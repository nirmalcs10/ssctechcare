3. Backend Technology Stack & Architecture

The backend is a lightweight, high-performance Node.js service providing RESTful JSON APIs and integrated single-process static file hosting.

Layer Technology Version Technical Role & Implementation Details
Runtime Node.js v20+ / v24 High-throughput asynchronous non-blocking event loop execution environment.
Framework Express.js v5.2.1 RESTful routing, middleware chaining, and HTTP request/response pipeline.
CORS cors v2.8.5 Cross-Origin Resource Sharing control across development ports.
Config dotenv v17.3 Environment variable management for configurable ports and paths.

API Endpoints Architecture:

  • /api/tickets - Full CRUD, state transitions, timeline audit logging, and parts association.
  • /api/inventory - Spare parts catalog, threshold warnings, and atomic quantity adjustments.
  • /api/customers - Customer database, phone uniqueness check, and previous repair histories.
  • /api/technicians - Staff directory, specialized skills, and active job counters.
  • /api/invoices - Billing engine, parts calculation, tax, discount, and payment records.
  • /api/track/:id - Customer self-service lookup by ticket number or mobile phone.
  • /api/dashboard - Real-time KPIs, active repair breakdown, urgent alerts, and revenue metrics.
  • /api/settings - Workshop profile, tax percentage, and printed legal disclaimers.

4. Database Engine & Relational Schema

The persistent data store is an embedded SQLite 3 database interfaced via better-sqlite3 (v13.0.3).

⚡ High Performance WAL Mode

Initialized with PRAGMA journal_mode = WAL (Write-Ahead Logging), allowing concurrent non-blocking reads while writing operations execute.

🛡️ Foreign Key Enforcement

Configured with PRAGMA foreign_keys = ON, ensuring relational integrity and cascading deletes across tickets, parts, and logs.

5. Core Business Logic & Atomic Workflows

1. Atomic Inventory Allocation

When replacement components are installed on a job card, the stock count in the warehouse is automatically decremented inside a transactional query: 

// 1. Deduct warehouse inventory
UPDATE inventory SET stock_quantity = stock_quantity - ? WHERE id = ?;

// 2. Attach part to job card
INSERT INTO ticket_parts (ticket_id, inventory_id, part_name, quantity, unit_price, total_price)
VALUES (?, ?, ?, ?, ?, ?);

// 3. Log into timeline audit trail
INSERT INTO timeline_logs (ticket_id, action, description, actor)
VALUES (?, 'Part Added', 'Installed RAM/SSD', 'Technician');

2. Financial & Tax Computation Logic

Invoices dynamically compute labor charges, installed parts totals, tax rates, and deduct collected advance deposits: 

Subtotal      = Parts Total + Labor Charges
Tax Amount    = Subtotal × (Tax Rate / 100)
Grand Total   = Subtotal + Tax Amount - Discount
Balance Due   = Grand Total - Advance Deposit - Amount Paid Now
